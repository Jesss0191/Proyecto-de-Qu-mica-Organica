## Cómo trabajar

1. Clonar: `git clone <url-del-repo>`
2. Crear una rama por tarea: `git checkout -b nombre/tarea`
3. Commits pequeños y con mensaje claro (ej. `Agrega gráfica de punto de ebullición vs masa molar`)
4. Subir y abrir Pull Request; otro integrante lo revisa antes de unir a `main`
5. Mover la tarjeta en el **Project** del repositorio (Por hacer → En curso → Hecho)
